Returns contract and system events from `startLedger` (or from a `cursor`), filtered by event type, contract and topics. The example reads events of the native XLM contract on Testnet. Pass the returned `cursor` to read the next page.

The examples call Testnet with your key in `LUMEUS_API_KEY`; the SDK tabs use `@stellar/stellar-sdk` and the Python `stellar-sdk` ([SDK setup and errors](/rpc/sdks)) (the curl example uses `jq`). On Mainnet, use `https://rpc.lumeus.dev` and a `lum_live_` key.

```python Python
import json
import os

import requests


def rpc(method, params=None):
    body = {"jsonrpc": "2.0", "id": 1, "method": method}
    if params is not None:
        body["params"] = params
    res = requests.post(
        "https://rpc-testnet.lumeus.dev",
        json=body,
        headers={"Authorization": f"Bearer {os.environ['LUMEUS_API_KEY']}"},
        timeout=30,
    )
    data = res.json()
    if "error" in data:
        raise RuntimeError(f"{data['error'].get('data')}: {data['error']['message']}")
    return data["result"]


latest = rpc("getHealth")["latestLedger"]
print(json.dumps(rpc("getEvents", {"startLedger": latest - 100, "filters": [{"type": "contract", "contractIds": ["CDLZFC3SYJYDZT7K67VZ75HPJVIEUVNIXF47ZG2FB2RMQQVU2HHGCYSC"]}], "pagination": {"limit": 2}}), indent=2))
```

```javascript JavaScript SDK
// npm install @stellar/stellar-sdk. Save as sdk.mjs and run: node sdk.mjs
import { rpc, scValToNative } from '@stellar/stellar-sdk';

const server = new rpc.Server('https://rpc-testnet.lumeus.dev', {
  headers: { Authorization: `Bearer ${process.env.LUMEUS_API_KEY}` },
});

const { latestLedger } = await server.getHealth();
const page = await server.getEvents({
  startLedger: latestLedger - 100,
  filters: [{ type: 'contract', contractIds: ['CDLZFC3SYJYDZT7K67VZ75HPJVIEUVNIXF47ZG2FB2RMQQVU2HHGCYSC'] }],
  limit: 2,
});
// topic and value arrive as xdr.ScVal; scValToNative decodes them (i128 amounts become BigInt).
const events = page.events.map(e => ({
  id: e.id,
  ledger: e.ledger,
  txHash: e.txHash,
  contractId: e.contractId?.contractId(),
  topic: e.topic.map(t => scValToNative(t)),
  value: scValToNative(e.value),
}));
console.log(JSON.stringify({ events, cursor: page.cursor }, (k, v) => (typeof v === 'bigint' ? v.toString() : v), 2));
```

## Result

The fields of `result` (stellar-rpc 29). Fields marked "Present only when it applies" can be absent.

| Field | Type | Description |
| --- | --- | --- |
| `events` | object[] | Matching events, oldest first. |
| `events[].type` | string | Event type. One of `contract`, `system`, `diagnostic`. |
| `events[].ledger` | integer | Ledger of the event. |
| `events[].ledgerClosedAt` | string | Close time (RFC 3339). |
| `events[].contractId` | string | C address of the emitting contract. |
| `events[].id` | string | Event ID, also usable as a cursor. |
| `events[].operationIndex` | integer | Zero-based operation index. |
| `events[].transactionIndex` | integer | Zero-based transaction index in the ledger. |
| `events[].txHash` | string | Hash of the transaction that emitted it. |
| `events[].inSuccessfulContractCall` | boolean | Deprecated by stellar-rpc: false when the call that emitted it failed. |
| `events[].topic` | string[] | Base64 ScVal XDR topics. Present only when it applies. |
| `events[].topicJson` | JSON[] | Decoded topics; only with xdrFormat json. |
| `events[].value` | string | Base64 ScVal XDR event data. Present only when it applies. |
| `events[].valueJson` | JSON | Event data. Decoded JSON; only with xdrFormat json. |
| `cursor` | string | Pass as pagination.cursor to read the next page. |
| `latestLedger` | integer | Latest ledger the node has. |
| `oldestLedger` | integer | Oldest ledger the node still keeps. |
| `latestLedgerCloseTime` | string | Close time of latestLedger. Unix seconds, as a string. |
| `oldestLedgerCloseTime` | string | Close time of oldestLedger. Unix seconds, as a string. |

## Parameters

| Name | Type | Rules |
| --- | --- | --- |
| `startLedger` | integer | First ledger, inside the retention window (see `getHealth`). Required unless `pagination.cursor` is set; not both. |
| `endLedger` | integer | Exclusive end; must be greater than `startLedger`. Not with a cursor. |
| `filters` | object[] | Up to 5 filters; an event matches when any filter matches. |
| `filters[].type` | string | `contract` or `system`. Omit for both. |
| `filters[].contractIds` | string[] | Up to 5 C contract addresses. |
| `filters[].topics` | array[] | Up to 5 topic filters, each 1 to 4 segments (base64 ScVal XDR, or `*` for any one value) plus an optional trailing `**`. Segments are at most 16 KiB. |
| `pagination.cursor` | string | Resume after the previous page. |
| `pagination.limit` | integer | 1 to 10,000, default 100. |
| `xdrFormat` | string | `base64` (default) or `json`. |

## Credits and limits

- **Mainnet:** 2 credits plus 1 credit per started 64 KiB of response, so a small answer costs 3 credits. A call that returns a JSON-RPC error costs nothing.
- **Testnet:** free. Each call counts toward your organization's 10,000 Testnet requests a day; above that, calls get 429 `rate_limited` until 00:00 UTC.
- Unknown filter fields are rejected with -32602. For full history beyond the 7-day window, use the Activity API (`GET /contracts/{id}/activity`).
- The plan RPC rate applies per call; each call in a batch counts as one.

## Errors

Gateway errors are JSON-RPC errors with the machine code in `error.data` and the request ID in `error.request_id`. Common ones: `-32602` (`invalid_request`, HTTP 400) for invalid params, `-32000` with `unauthorized` (401), `rate_limited` (429, wait `Retry-After` seconds) or `unavailable` (503). See [errors](/guides/errors).
