Returns a transaction's status (`SUCCESS`, `FAILED` or `NOT_FOUND`), its ledger, and its envelope, result and metadata XDR. RPC keeps about 7 days: an older or unknown hash answers `NOT_FOUND` (still HTTP 200). For older transactions, read the indexed header from the Activity API (`GET /transactions/{hash}`). The examples first pick a recent hash with `getTransactions`.

The examples call Testnet with your key in `LUMEUS_API_KEY`; the SDK tabs use `@stellar/stellar-sdk` and the Python `stellar-sdk` ([SDK setup and errors](/rpc/sdks)) (the curl example uses `jq`). On Mainnet, use `https://rpc.lumeus.dev` and a `lum_live_` key.

```python Python
import json
import os

import requests


def rpc(method, params=None):
    body = {"jsonrpc": "2.0", "id": 1, "method": method}
    if params is not None:
        body["params"] = params
    res = requests.post(
        "https://rpc-testnet.lumeus.dev",
        json=body,
        headers={"Authorization": f"Bearer {os.environ['LUMEUS_API_KEY']}"},
        timeout=30,
    )
    data = res.json()
    if "error" in data:
        raise RuntimeError(f"{data['error'].get('data')}: {data['error']['message']}")
    return data["result"]


latest = rpc("getHealth")["latestLedger"]
txs = rpc("getTransactions", {"startLedger": latest - 10, "pagination": {"limit": 1}})
print(json.dumps(rpc("getTransaction", {"hash": txs["transactions"][0]["txHash"]}), indent=2))
```

```javascript JavaScript SDK
// npm install @stellar/stellar-sdk. Save as sdk.mjs and run: node sdk.mjs
import { rpc } from '@stellar/stellar-sdk';

const server = new rpc.Server('https://rpc-testnet.lumeus.dev', {
  headers: { Authorization: `Bearer ${process.env.LUMEUS_API_KEY}` },
});

const { transactions } = await server.getTransactions({ startLedger: latestLedger - 10, pagination: { limit: 1 } });

// envelopeXdr, resultXdr and resultMetaXdr arrive parsed as XDR objects
// (and returnValue, for a successful contract call).
const { status, txHash, ledger, createdAt, applicationOrder, feeBump } = tx;
console.log(JSON.stringify({ status, txHash, ledger, createdAt, applicationOrder, feeBump }, null, 2));
```

## Result

The fields of `result` (stellar-rpc 29). Fields marked "Present only when it applies" can be absent.

| Field | Type | Description |
| --- | --- | --- |
| `latestLedger` | integer | Latest ledger the node has. |
| `latestLedgerCloseTime` | string | Close time of latestLedger. Unix seconds, as a string. |
| `oldestLedger` | integer | Oldest ledger the node still keeps (about 7 days back). |
| `oldestLedgerCloseTime` | string | Close time of oldestLedger. Unix seconds, as a string. |
| `status` | string | SUCCESS, FAILED, or NOT_FOUND (unknown, or older than the retention window). |
| `txHash` | string | Transaction hash (of the fee-bump transaction for a fee bump). |
| `applicationOrder` | integer | Position of the transaction in its ledger (1-based; 0 when NOT_FOUND). |
| `feeBump` | boolean | True for a fee-bump transaction. |
| `envelopeXdr` | string | TransactionEnvelope. Base64 XDR (with xdrFormat json, the matching Json field instead). Present only when it applies. |
| `envelopeJson` | JSON | TransactionEnvelope. Decoded JSON; only with xdrFormat json. |
| `resultXdr` | string | TransactionResult. Base64 XDR (with xdrFormat json, the matching Json field instead). Present only when it applies. |
| `resultJson` | JSON | TransactionResult. Decoded JSON; only with xdrFormat json. |
| `resultMetaXdr` | string | TransactionMeta. Base64 XDR (with xdrFormat json, the matching Json field instead). Present only when it applies. |
| `resultMetaJson` | JSON | TransactionMeta. Decoded JSON; only with xdrFormat json. |
| `diagnosticEventsXdr` | string[] | Base64 DiagnosticEvent XDR, when diagnostics are recorded. Present only when it applies. |
| `diagnosticEventsJson` | JSON[] | Decoded diagnostic events; only with xdrFormat json. |
| `events` | object | The transaction's events. Present only when it applies. |
| `events.transactionEventsXdr` | string[] | Base64 TransactionEvent XDR (for example fee events). Present only when it applies. |
| `events.transactionEventsJson` | JSON[] | Decoded transaction events; only with xdrFormat json. |
| `events.contractEventsXdr` | string[][] | Base64 ContractEvent XDR, one inner list per operation. Present only when it applies. |
| `events.contractEventsJson` | JSON[][] | Decoded contract events; only with xdrFormat json. |
| `ledger` | integer | Ledger that included the transaction (0 when NOT_FOUND). |
| `createdAt` | string | Close time of the including ledger ("0" when NOT_FOUND). Unix seconds, as a string. |

## Parameters

| Name | Type | Rules |
| --- | --- | --- |
| `hash` | string | Required. 64-character hexadecimal transaction hash. |
| `xdrFormat` | string | `base64` (default) or `json`. |

## Credits and limits

- **Mainnet:** 1 credit plus 1 credit per started 64 KiB of response, so a small answer costs 2 credits. A call that returns a JSON-RPC error costs nothing.
- **Testnet:** free. Each call counts toward your organization's 10,000 Testnet requests a day; above that, calls get 429 `rate_limited` until 00:00 UTC.
- Response ceiling 8 MiB.
- The plan RPC rate applies per call; each call in a batch counts as one.

## Errors

Gateway errors are JSON-RPC errors with the machine code in `error.data` and the request ID in `error.request_id`. Common ones: `-32602` (`invalid_request`, HTTP 400) for invalid params, `-32000` with `unauthorized` (401), `rate_limited` (429, wait `Retry-After` seconds) or `unavailable` (503). See [errors](/guides/errors).
