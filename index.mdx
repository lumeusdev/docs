## Try it

With a Testnet key, one request lists the three largest XLM holders on Testnet:

```bash
export LUMEUS_API_KEY='paste-your-lum_test_-key'

curl --fail-with-body -sS -G 'https://assets-testnet.lumeus.dev/assets/native/holders' \
  --data-urlencode limit=3 \
  -H "Authorization: Bearer $LUMEUS_API_KEY" |
  jq -r '._embedded.records[] | "\(.balance) XLM  \(.holder)"'
```

```text Output
53757260427.8488203 XLM  GBFAIH5WKAJQ77NG6BZG7TGVGXHPX4SQLIJ7BENJMCVCZSUZPSISCLU5
7056467984.5299856 XLM  GAIH3ULLFQ4DGSECF2AR555KZ4KNDGEKN4AFI4SU2M7B43MGK3QJZNSR
206509999.7935000 XLM  GATXZXYXXG4ARRZC4G7KYK3OXQFSR4DWPXWJ7R6TEG3J6LPUFDV745EY
```

## Plans

Build and test on Testnet for free: up to 10,000 requests a day, reset at
00:00 UTC, on every plan (unlimited on Enterprise). Credits are for Mainnet.
Every workspace starts on Free, with 250,000 Mainnet credits a month and one
Testnet webhook endpoint. Starter, Growth and Scale add credits, higher rate
limits and webhooks on both networks. Upgrade any time in the dashboard. See
[plans and billing](/guides/billing).

## History and retention

Activity covers the full history of supported events, back to genesis on
Mainnet. RPC keeps about seven days of recent ledgers; use the Activity API for
anything older. See [event coverage](/activity/events) and
[health checks](/guides/readiness).
