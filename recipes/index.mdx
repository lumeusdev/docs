---
title: Recipes
description: End-to-end tasks with Lumeus, each runnable in curl, JavaScript and Python.
---

Each recipe solves one task from start to finish on Testnet, with code you can
paste and a real response. They use the shared [Testnet setup](/quickstart) and
cost nothing on Testnet. Pick the one closest to what you are building.

| Recipe | What it does | Products |
| --- | --- | --- |
| [Last payments](/recipes/last-payments) | List the 10 most recent payments an account sent or received, newest first. | Activity API |
| [Wallet portfolio](/recipes/wallet-portfolio) | List every asset a wallet holds, with balances and what it can spend. | Assets API |
| [Top holders](/recipes/top-holders) | Rank the largest holders of an asset and their share of supply. | Assets API |
| [Sync account history](/recipes/sync-account) | Copy an account's full history into your database, then keep it current; safe to stop and resume. | Activity API |
| [Follow contract events](/recipes/watch-contract) | Read a Soroban contract's events from a ledger onward, keep following new ones, and filter by an address in a topic. | Activity API |
| [Airdrop snapshot](/recipes/airdrop-snapshot) | List every holder of a token at a past ledger and compute each one's share for an airdrop. | Assets API |
| [RPC event pages](/recipes/rpc-events) | Read a contract's recent events with `getEvents`, page with the cursor, and keep up with new ledgers. | RPC |
| [Balance alerts](/recipes/balance-alerts) | Get a signed webhook with the new balance whenever a wallet's balance changes, and alert below a threshold. | Webhooks |

New to Lumeus? Start with the [quickstart](/quickstart), then come back here.
